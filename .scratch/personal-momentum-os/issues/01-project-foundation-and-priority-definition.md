# 01: Project Foundation & Priority Definition Tracer Bullet

**What to build:** The user can define their life structure by creating Life Directions, Areas within those directions, and persistent Priorities within Areas. For each Priority, the user sets custom plain-text operating definitions for what constitutes a Spark, Fire, Cook Session, and Synthesis, along with an initial operating phase (`SPARK`, `FIRE`, or `COOK`). The user can view and manage their active priorities in a responsive dashboard interface.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] User can create, edit, list, and delete Life Directions and Areas.
- [ ] User can create and edit Priorities with custom operating definitions (`spark_definition`, `fire_definition`, `cook_definition`, `synthesis_definition`) and an initial phase.
- [ ] User can view all active priorities organized by Area in a clean UI.
- [ ] Domain models and database tables are set up with proper user isolation and validation.
- [ ] End-to-end automated integration tests verify priority creation, definition updates, and listing.
